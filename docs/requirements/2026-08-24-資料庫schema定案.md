## 決策記錄

| 主題 | 決策 | 理由 |
|---|---|---|
| Primary key 型別 | UUID | 避免 ID 被猜測列舉，未來多租戶/資料合併較安全，純技術選型不影響需求 |
| daily_logs 是否拆表 | 不拆，維持進食+排便+體重合併一筆 | 對應 2026-08-23 紀錄功能重新規劃書中「排便、體重維持現狀」的決定，且符合現有 UX（一天填一次表單） |
| environment_logs 時間欄位 | timestamp（非 date） | 使用者確認：雖然目前手動輸入是每日一次，但未來 IoT 感測器會高頻寫入，用 timestamp 才不用之後改 schema |
| 性別欄位 | enum('male','female','unknown') | 對應 2026-08-24 需求書；現有程式碼其實已有「未知」選項，README 描述不完整，這裡以實際程式碼行為為準 |
