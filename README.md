# 肥尾日誌 · Fat-Tailed Gecko Log

肥尾守宮（*Hemitheconyx caudicinctus*）飼育紀錄工具。單一 HTML 檔，無後端、無建置流程，開啟即用。

## 功能

- **多隻管理**：每隻獨立的名字、品系（多基因不限字數）、性別、出生日、入手日、照片、餵食頻率
- **每日紀錄**：進食數量、餌料種類與尺寸、排便、體重、備註
- **狀態區分**：數量為 0 時可標記為「拒食」或「沒餵（非餵食日）」，非餵食日不會被誤計為拒食
- **60 天斑帶圖**：以守宮橫紋呈現，區分進食／拒食／沒餵／排定日未記錄／非餵食日
- **體重曲線**：含與前次量測的增減
- **進食量圖表**：可切換 天 / 週 / 餵食週期 / 月 / 年 五種顆粒度
- **餌料組成**：依「餌料＋尺寸」統計比例
- **Excel 匯出／匯入**：含照片，可完整還原

## 使用

直接開啟 `index.html`，或部署到任何靜態主機。

## 資料儲存

存在瀏覽器的 `localStorage`，key 為 `fattail-gecko-log-v1`。

因此請注意：

- 資料綁定**單一瀏覽器**，換裝置或清除瀏覽資料會遺失
- 請定期使用「匯出 Excel」備份（匯出檔含照片，可完整還原）

若需跨裝置同步，需接資料庫（Supabase 等），見下方 Roadmap。

## 相依套件

[SheetJS](https://sheetjs.com/) 0.18.5，由 cdnjs CDN 載入，處理 Excel 匯出匯入。其餘皆為原生 JavaScript，圖表為手寫 SVG。
